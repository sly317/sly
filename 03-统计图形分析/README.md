# 03-统计图形分析

> 状态：目录初始化，分析工作暂未启动。建立日期：2026-11-23。

本目录用于研究信息图形案例中所采用的**统计图形及其所需数据结构**，作为“01-信息图形数据逻辑”与“02-信息图形类型案例”的方法支持。

## 研究范围（后续开展）

- 数据结构：字段、观测单位、数据类型、表格关系及图形适配条件。
- 统计关系：比较、分布、排序、时间变化、组成、关联、流向、层级、空间等。
- 统计处理：分组、聚合、归一化、比例计算、排序、尺度和缺失数据处理。
- 图形编码：位置、长度、面积、颜色、形状、连线、密度与图例。
- 案例关联：分析使用了哪些统计图形、为什么适合该数据、是否存在误读风险，并链接到02中的具体案例。

## 当前边界

已初步查阅 RAWGraphs 应用仓库的 README、`src/charts.js`、`package.json` 和示例数据文件目录。该应用支持表格数据，并提供多种图形的入口，但**本目录尚未形成单项图形分析、分类结论或案例报告**。后续应在明确指令后再依据源码、样本数据与图形行为逐项核实。
