# 信息图形类型案例

本目录以**视觉表达形式／传播格式**为主轴（区别于01的数据逻辑分类），目前预置三个类型，按案例逐步完善：

1. [混合型信息图形（Mixed Charts）](./01-混合型信息图形/说明文档.md)
2. [文字型／列表型信息图形（Informational / List Infographics）](./02-文字型-列表型信息图形/说明文档.md)
3. [时间轴型信息图形（Timeline Infographics）](./03-时间轴型信息图形/说明文档.md)

## 工作流
用户提供案例图→保留原图和出处→创建独立分析报告→分析数据逻辑、统计方式、视觉编码、信息架构、叙事架构→更新对应类型说明→必要时更新[01数据逻辑定义](../01-信息图形数据逻辑/README.md)并互链。

**当前没有用户提供的图形案例，所有类型说明均为v0.1的待检验框架，而非已验证总结。**
