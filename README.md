# 信息图形数据逻辑与类型案例研究库

本仓库用于长期研究信息图形（Infographics）的**数据组织逻辑、统计图形借用、视觉编码、信息架构和视觉叙事**，通过持续增加的真实案例检验、修订与丰富类型定义。

## 仓库目录

- [01-信息图形数据逻辑](./01-信息图形数据逻辑/README.md)：5类基础逻辑与A—E分析维度。**仅存理论说明，不保存图片。**
- [02-信息图形类型案例](./02-信息图形类型案例/README.md)：混合型、文字型／列表型、时间轴型三种初始视觉类型，独立案例图像、分析报告及归纳文档。

## 理论与案例双轴分类

01回答“**数据本身如何被组织**”；02回答“**内容采用何种信息图形表达形式**”。两个分类轴不能简单等同，一个图形可具有多重数据逻辑及多种视觉表达方式。

## A—E统一分析维度

A. 基础数据逻辑／字段／关系。 B. 统计图形、聚合与计算。 C. 点、线、面、体、符号、色彩和文字的视觉编码。 D. 数据／信息架构。 E. 视觉叙事架构。

## 案例驱动维护原则

1. 用户提供原图后，先保存原文件、出处、授权状态与案例ID，禁止虚构案例。
2. 每图单独创建分析报告，区分图面可见事实、推断与无法核实的信息。
3. 通过相对Markdown链接，把案例报告与01理论定义、02类型说明关联起来。01不存图。
4. 归纳文档只在真实案例支持下补充或修订，并写明适用前提、反例、修改时间和证据路径；保留历史提交以供追溯。
5. **更新触发方式**：当用户向本对话提供新案例并要求入库时执行实际更新；GitHub仓库不会自行监视对话或在无人触发时自动改写。
